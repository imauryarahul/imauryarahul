### 🧩 What I've Been Building

**Neusearch AI — Co-founded & Sold (Jun 2025 - Apr 2026)**

Started with a sharp insight: as users shifted from Google to ChatGPT and Perplexity, D2C brands had zero visibility into how, or whether, they showed up in AI-generated responses.

Built lean with my co-founder Ankit:

- A **GEO (Generative Engine Optimization) platform** to help brands monitor and improve their presence across AI search surfaces
- A **RAG-based Shopify shopping assistant** that understood product catalogs and surfaced recommendations conversationally (internal build, tested in one pilot)
- A **brand audit engine**, redesigned from a slow linear pipeline into a parallel multi-agent architecture, cutting report generation from 15 minutes to under 3 while eliminating data inaccuracies and reducing API costs
- A **cross-domain memory-sharing POC** for personalization without requiring user login

Sold the product within 10 months of founding.

**Since then**, I've been sharpening my AI builder toolkit while exploring the right next role:

- Experimenting with building autonomous **AI agents** for real-world workflows using Claude Code and Cursor

- Treating the job search itself like a product problem, testing positioning, messaging, and outreach the same way I'd test a feature
